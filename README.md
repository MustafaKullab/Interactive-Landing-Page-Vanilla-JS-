# 🎨 Interactive Landing Page — Vanilla JavaScript

A responsive and interactive landing page built with **HTML, CSS, and Vanilla JavaScript**.

This project focuses on practicing core frontend concepts such as **DOM manipulation, event handling, responsive layouts, localStorage, interactive UI controls, and dynamic page behavior without using a framework**.

> 🚀 **Live Demo:** [Open Interactive Landing Page](https://interactive-landing-page-js.vercel.app/)

## ✨ Features

### 🎛️ Interactive Settings

* Change the main theme color
* Enable or disable automatic background image rotation
* Show or hide navigation bullets
* Save user preferences with `localStorage`
* Reset all settings to their default values

### 🧭 Navigation

* Responsive navigation menu
* Mobile toggle menu
* Smooth scrolling between sections
* Navigation through header links and section bullets

### 🖼️ Interactive Gallery

* Click images to open a lightbox
* Overlay background
* Image title display using `alt` text
* Close the image viewer from the close button or overlay

### 📊 Skills Animation

* Skill progress bars start at `0%`
* Progress values animate when the user reaches the Skills section while scrolling

### 📱 Responsive Design

* Responsive layout for desktop, tablet, and mobile screens
* Mobile navigation behavior
* Responsive content sections and gallery

### 🧩 Page Sections

* About
* Skills
* Gallery
* Timeline
* Features
* Testimonials
* Contact

## 🚀 Getting Started

This is a static frontend project, so no backend or package installation is required.

### Run Locally

Clone the repository:

```bash id="8u1t1f"
git clone https://github.com/MustafaKullab/Interactive-Landing-Page-Vanilla-JS-.git
cd Interactive-Landing-Page-Vanilla-JS-
```

Then open:

```text id="7l2f1u"
index.html
```

in your browser.

## 🎯 Project Goal

This project was built as a hands-on practice project to strengthen frontend fundamentals before moving toward framework-based development.

The main focus was building interactive behavior with **plain JavaScript**, without relying on Vue, React, or other frontend frameworks.
